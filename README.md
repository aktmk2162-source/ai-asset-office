# AIアセット｜動く全社オフィス

12の部署で働く様子を描く、ブラウザー用のアニメーションです。
パソコン作業、相談への移動、資料リレー、共用スペースの打合せを別々のタイミングで繰り返します。

## 操作

- 「一時停止」「速さ」で動きを調整できます。初期設定は「せわしなく」で、「ゆっくり」「大忙し」にも切り替えられます。
- 部屋または部署選択で、注目する部署を切り替えられます。
- 「全画面」でオフィスを大きく表示できます。
- 対応するブラウザーでは「動画を録画」で、音声なしのWebM動画を端末に保存できます。最長2分です。

## 公開デモについて

人物や作業はすべて演出です。実際の社員数、業務状況、AIの稼働状況を示すものではありません。
実ログや社内システムに接続しません。社内資料、実行履歴、認証情報を含みません。
ブラウザー内だけで描画します。追加API、外部フォント、外部ライブラリーは使用しません。

## 配信

`index.html`、`style.css`、`app.js`を静的サイトとして配信できます。
GitHub Pagesではブランチのルートディレクトリーを公開元にします。
